# Relay Console bridge plugins v0.3.0-rc.2

Status: preview release candidate; not a stable customer release.

This candidate upgrades both external bridges to bridge API v2. Device
authentication now consumes the submitted device credential and returns a
replacement alongside the short-lived HTTP and websocket tokens.

Hermes atomically replaces its owner-only JSON configuration using a unique
temporary file, file and directory synchronization, and symbolic-link refusal.
OpenClaw serializes authentication for each device and uses OpenClaw's native
configuration writer to replace the correct account credential. Both bridges
withhold returned bearer tokens until persistence succeeds and retain the
replacement in process so a transient write failure can be retried without
reusing the consumed credential.

The remaining preview gaps are declared in `compatibility-manifest.json`.
Stable release still requires clean-host lifecycle records, cross-client live
acceptance, and a pinned backend release commit.
