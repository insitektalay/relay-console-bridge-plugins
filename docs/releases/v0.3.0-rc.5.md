# Relay bridge plugins v0.3.0-rc.5

This preview release corrects Hermes bridge authentication and expands safe-mode support for managed Marketplace skill installation.

- Hermes now keeps the HTTP access token and WebSocket token in their separate security scopes.
- Legacy servers that return one `token` value remain supported.
- Safe-mode Hermes runtimes may install Relay-managed Marketplace skill packs; other unverified capabilities remain disabled.
- Hermes Agent bridge plugin version is `0.3.0-rc.4`.
