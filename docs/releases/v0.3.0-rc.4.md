# Relay Console bridge plugins v0.3.0-rc.4

Preview release isolating the Hermes bridge from user-managed Python packages.

## Changes

- The Hermes lifecycle creates a private bridge Python environment and runs
  enrollment, services, health checks, and credential rotation with it.
- The bridge installs `aiohttp>=3.10,<4` privately while continuing to load the
  selected Hermes checkout and its other dependencies read-only.
- Hermes installations carrying a different aiohttp 3.x release no longer need
  to be modified for Relay, and update failures preserve the active bridge.
- Uninstall removes the private bridge environment but preserves Hermes and the
  enrolled device credential.

## Known gaps

Clean-host lifecycle acceptance and cross-client dispatch evidence remain to be
recorded before a stable release.
