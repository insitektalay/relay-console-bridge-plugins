# Relay Console bridge plugins v0.3.0-rc.1

Status: preview release candidate; not a stable customer release.

This candidate makes Runtime Connector Protocol v3 the default for Hermes and
OpenClaw. Discovery now sends native identity and safe display metadata first.
Instructions, memory, and Markdown skills remain on the runtime until a Relay
administrator explicitly connects the candidate and accepts the document
boundary.

Hermes adds native default/named profile discovery through the supported Hermes
profile API, fixed-profile worker processes, bounded worker restart and idle
policies, profile-aware dispatch/skills/cron operations, durable idempotent
native profile creation, and durable completion callback replay.

OpenClaw adds metadata-first native registry discovery and durable, shell-free,
idempotent provisioning with path, symlink, secret-name, and size checks.

Both plugins retain narrowly negotiated v2 and v1 fallbacks. Authentication,
validation, conflict, rate-limit, and server failures never cause a downgrade.
Fallback inventory cannot establish a new canonical mapping or upload
documents before Relay consent. `agent-replica.v1` is limited to existing
bindings through 30 September 2026; `relay-connector.v2` supports existing
bindings and metadata-only discovery through 31 October 2026. Connector v3 is
the only consent-capable current protocol.

Known release gaps remain declared in `compatibility-manifest.json`. A stable
tag still requires clean-host lifecycle records, cross-client live acceptance,
and a pinned backend release commit.
