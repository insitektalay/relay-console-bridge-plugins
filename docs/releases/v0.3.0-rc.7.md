# Relay bridge plugins v0.3.0-rc.7

This release keeps locally configured and natively discovered Hermes agents registered with Relay even when the optional cloud replica exchange is empty or temporarily unavailable.

- Hermes Agent bridge plugin version is `0.3.0-rc.6`.
- Agent routing remains available when replica discovery is awaiting consent or its HTTP request fails.
- Periodic replica synchronization can no longer erase the bridge's locally routable agent inventory.
