# Relay Console bridge plugins v0.3.0-rc.3

Preview release adding server-negotiated runtime compatibility tiers.

## Changes

- The guided installer performs compatibility preflight before requesting or
  consuming a one-time enrollment code.
- Hermes and OpenClaw distinguish exact verified runtimes from compatible
  version families and run unverified combinations with a minimal safe
  capability set.
- Unsupported hosts, bridge/API protocol mismatches, known-incompatible
  versions, and versions below the declared floor remain blocked.
- The compatibility manifest advances to schema v2 and records verified
  versions, compatible ranges, unknown-version behavior, and safe-mode
  capabilities.

## Known gaps

Clean-host lifecycle acceptance and cross-client dispatch evidence remain to be
recorded before a stable release. Safe-mode admission is deliberately narrower
than full verification.
