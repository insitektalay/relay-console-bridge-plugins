# Relay Console bridge plugins v0.2.0-rc.1

Status: preview; not a stable customer release.

Supported Relay backend version: `1.0.0`. The backend compatibility baseline is
intentionally unpinned while this candidate and the product release candidate
remain unfrozen; stable promotion refuses that state.

This candidate adds authenticated outbound Relay Cloud connectivity for the
pinned Hermes Agent and OpenClaw runtimes, one-time device enrollment,
credential rotation, reconnect/backfill and duplicate suppression, explicit
compatibility reporting, and documented install/update/rollback/uninstall
lifecycle commands.

The Hermes bridge declares and verifies `aiohttp==3.14.1`, matching the pinned
Hermes release. Relay does not install or upgrade that package: a user whose
Hermes environment lacks the exact dependency receives a fail-closed
instruction before the active bridge or service is changed.

The lifecycle scripts stage and validate updates before activation, restore the
working bridge when activation fails, preserve the user's runtime and device
configuration on uninstall, safely generate launchd/systemd definitions, and
exclude development dependencies and tests from the OpenClaw installation.

Known release gaps: clean supported macOS/Linux hosts and the full macOS, web,
iPhone, and iPad dispatch journey have not yet passed, and the backend release
baseline commit is not frozen. No stable tag or customer release should be created from
this candidate.
