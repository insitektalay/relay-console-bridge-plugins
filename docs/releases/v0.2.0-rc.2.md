# Relay Console bridge plugins v0.2.0-rc.2

Status: preview release candidate; not a stable customer release.

This candidate makes Runtime Connector Protocol v2 the default for the Hermes
and OpenClaw bridges while retaining `agent-replica.v1` as a narrowly negotiated
fallback. The websocket contract remains `bridge.v1`.

Connector v2 adds:

- stable canonical Relay agent mappings returned by Railway and persisted by
  each runtime bridge;
- runtime-host software/protocol observations;
- deterministic managed-document manifest hashes;
- `completeManifest` reporting that fails closed when agent or document limits
  truncate a scan;
- collision-safe registration, because only agents accepted by the exchange
  are registered on the websocket;
- atomic runtime document application with the existing optimistic-concurrency
  and tombstone behavior; and
- downgrade protection: only an explicit unsupported-protocol response can
  select v1, never an auth, validation, conflict, rate-limit, or server error;
  and
- authenticated Hermes model-catalog publication, so Relay's web and mobile
  model pickers can follow the models exposed by the connected Hermes
  installation.

The candidate also preserves the existing workspace-scoped Hermes layout and
OpenClaw agent workspace resolution introduced in the unreleased local work.

Known release gaps remain intentionally declared in the compatibility
manifest. Clean-host macOS/Linux records, the independently reviewed
cross-client matrix, and an exact backend commit are still required before a
stable release. No stable tag or customer release should be created from this
candidate yet.
