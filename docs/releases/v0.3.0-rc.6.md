# Relay bridge plugins v0.3.0-rc.6

This preview release makes Hermes bridge activation and agent registration reliable during guided installation.

- macOS launchd activation retries the transient `Bootstrap failed: 5` race before rolling back.
- Guided Hermes installation accepts repeated `--agent` values and registers those runtime identities during enrollment.
- Hermes Agent bridge plugin version is `0.3.0-rc.5`.
