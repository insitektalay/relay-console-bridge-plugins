# Security Policy

Please do not disclose bridge vulnerabilities, enrollment codes, device
credentials, runtime credentials, or private logs in a public GitHub issue.

Use GitHub's private vulnerability reporting for this repository. Include the
affected commit or preview version, runtime type, host operating system, and a
minimal reproduction with all credentials and personal data removed.

Operational credential, transport, storage, and revocation guidance is in
[`docs/SECURITY.md`](docs/SECURITY.md).
